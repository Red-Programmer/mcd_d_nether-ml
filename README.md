# ![Dungeons Dimensions Nether](https://cdn.modrinth.com/data/cached_images/f58ba10ea3efc5c11e8395a798d493c486e1280f.png)

A project to enhance Minecraft's Nether using content from Minecraft: Dungeons
<br></br>
[![Trailer](https://i3.ytimg.com/vi/jBDUeJ7VOZI/maxresdefault.jpg)](https://youtu.be/jBDUeJ7VOZI)
<br></br>
Dungeons Dimensions: Nether adds new Blocks and Foliage, updates existing block models and textures, and adds new world generation, all based on how they appear in Minecraft: Dungeons.

## New Nether Fortresses!
Dungeons Dimensions: Nether now updates the Nether Fortress to resemble it's Dungeons Appearance
![Fortress](https://cdn.modrinth.com/data/sf8l9B73/images/08ff5807732cce17d1a779556cad1698ff9241ef.png)

## Compatibility
This mod is compatible with Amplified Nether!
